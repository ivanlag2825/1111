# Historical Reality: Total War 1936–1946 — 0.3

Переработка исторических кампаний Германии и СССР для двух игроков друг против друга. Исторические условия, свободный исход, высокая сложность, все DLC. Альтернативные политические маршруты сохранены.

[Скачать rework.zip](https://github.com/ivanlag2825/1111/raw/refs/heads/mod-main-tree/dist/rework.zip)

В обычные деревья встроен 81 новый крупный фокус. У 67 исходных фокусов изменены обязательные предпосылки; 32 ключевых перехода проверены на отсутствие обходного пути. Предприятия, сильные исследовательские ускорения, снятие ограничений и девять пар специализаций меняют развитие страны. Есть 36 программ решений и 20 условных событий. Исходные награды и внешние механики DLC сохранены.

## Установка

Распакуй папку `historical_reality_overhaul` и файл `historical_reality_overhaul.mod` из ZIP в `Документы/Paradox Interactive/Hearts of Iron IV/mod`. При обновлении 0.2 замени её папку этой версией. Отключи прежний HRS 0.1 и другие моды деревьев GER/SOV, включи Historical Reality: Total War в лаунчере. Оба игрока используют одинаковый архив, игру и DLC; нужна новая кампания 1936 года. Python не нужен.

В папке мода открой `preview/index.html` для схемы с поиском и масштабированием. Это схема скриптов, а не снимок из игры.

## Исходники и проверки

[Описание и сборка](overhaul/README.md), [Германия](overhaul/docs/GER_REWORK_RU.md), [СССР](overhaul/docs/SOV_REWORK_RU.md), [проверка в игре](overhaul/docs/TESTING_PVP_RU.md).

```bash
python3 -m unittest discover -s overhaul/tests -v
```

Эта версия прошла статическую проверку скриптов, связей, координат, локализации и упаковки. В облачной среде нет HOI4: отображение скрытых веток и сетевой баланс ещё требуют проверки в игре. Маска поддерживаемой версии лаунчера не подтверждает совместимость с будущими обновлениями. Сборщик работает с предоставленными исходными деревьями и записывает их контрольные суммы.

Старые архивы сохранены: [проверенная пользователем 0.1](https://github.com/ivanlag2825/1111/raw/refs/heads/mod-download/dist/mod.zip), [прежняя 0.2](https://github.com/ivanlag2825/1111/raw/refs/heads/mod-overhaul/dist/overhaul.zip).
