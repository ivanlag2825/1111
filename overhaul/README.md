# Historical Reality: Total War 1936–1946 — 0.4.0

Переработка исторических маршрутов Германии и СССР для двух игроков друг против друга, со всеми DLC. Исторические условия и свободный исход; политические альтернативы сохранены.

81 крупный новый фокус встроен в обычные деревья, у 67 исходных узлов изменены предпосылки. Для 32 ключевых переходов проверена обязательность нового этапа. Связи и сроки 0.3 сохранены; в 0.4 усилены специализации и реальные награды, добавлены военные кризисы и адаптация. Панель непрерывных фокусов перемещена ниже дерева и включена в интерактивную схему.

Германская серийная школа достигает +25% выпуска/+25% предела эффективности с ценой освоения новых моделей; гибкая — +40% роста/+35% сохранения эффективности. Советская промышленность получает до +25% выпуска, оборонная строительная школа — до +45% военного строительства. Девять пар программ требуют выбора специализации. Строительные очереди увеличены; контроль областей, вместимость и компенсация проверяются.

В первой оборонительной войне с Германией СССР получает крупный кризис на 120 фактических дней войны. Германия получает ограничения зимнего Восточного фронта. Основные фокусы готовят страну, закрепляют реформы и превращают опыт в положительные духи после 120 военных либо 45 зимних военных дней. Мир, лето и капитуляция учитываются; повторные бонусы не выдаются. Существующие духи и механики DLC не удаляются.

## Разработка

Python 3.10+, сторонние пакеты не нужны. Нужны исходные `common/national_focus/germany.txt` и `soviet.txt` соответствующей игры; сборщик их только читает.

```bash
python3 overhaul/tools/build_overhaul.py --game-dir /path/to/hoi4 --output-dir /path/to/new-build --schema-dir /path/to/cwtools-hoi4-config --archive /path/to/war.zip
python3 -m unittest discover -s overhaul/tests -v
```

Готовый ZIP устанавливается папкой мода и переносимым `.mod`, без Python. При обновлении замените папку старой версии. Нужна новая кампания 1936: старые сохранения не содержат историю новых счётчиков. Оба игрока устанавливают одинаковый архив. Внутри `preview/index.html` — схема с поиском и переходом к панели непрерывных фокусов.

Скрипты, графы, бонусы, локализация, сохранение исходных эффектов, военные состояния и координаты проверены автоматически. Исполняемой HOI4 в среде нет; отображение GUI и сетевой баланс требуют живого теста. После обновления игры нужна проверка соответствия исходных файлов.
