# Historical Reality: Total War 1936–1946 — 0.3.0

Глубокая переработка исторических маршрутов Германии и СССР для двух игроков друг против друга, со всеми DLC. Исторические условия и свободный исход; альтернативные политические маршруты сохранены.

81 новый крупный фокус встроен в обычные деревья: 40 германских и 41 советский. У 67 исходных узлов переписаны предпосылки. Для 32 ключевых переходов проверено, что новый этап обязателен на каждом совместимом пути. Секторы получили новые промежуточные ряды, развилки и соединения направлений. Используются 70 разных значков, уже присутствующих в предоставленных деревьях игры.

Награды включают реальные предприятия, 75–100% исследовательские бонусы, дополнительную ячейку с 1943 года при текущем числе менее шести, снятие ограничений и сильные национальные реформы. Девять взаимоисключающих пар требуют специализации. 36 программ решений и 20 условных событий дополняют основное развитие. Семейства духов заменяют предыдущие ступени, не дублируют их. Все 749 исходных ID и исходные награды/вызовы DLC сохранены; MEFO, паранойя, реабилитация и эвакуация работают через исходные системы.

[Переработка Германии](docs/GER_REWORK_RU.md), [СССР](docs/SOV_REWORK_RU.md), [выборы](docs/CHOICES_RU.md), [проверка двух игроков](docs/TESTING_PVP_RU.md).

## Разработка

Python 3.10+, без сторонних пакетов. Нужны пользовательские исходные `common/national_focus/germany.txt` и `soviet.txt`; сборщик их только читает.

```bash
python3 overhaul/tools/build_overhaul.py --game-dir /path/to/hoi4 --output-dir /path/to/new-build --schema-dir /path/to/cwtools-hoi4-config --archive /path/to/rework.zip
python3 -m unittest discover -s overhaul/tests -v
```

Готовый ZIP не требует Python: папка мода и переносимый `.mod` распаковываются в пользовательскую папку `mod`. Старые версии надо выключить. Новая кампания 1936 года обязательна. Внутри есть интерактивная схема `preview/index.html` с поиском и масштабированием.

Скрипты, графы, ссылки, локализация, сохранение исходных эффектов и базовые координаты проверяются автоматически. Эта версия ещё не запущена в HOI4; отображение с учётом скрытых веток, сетевой баланс и игровые журналы требуют живой проверки. При очередном обновлении игры нужны соответствующие исходные файлы.
